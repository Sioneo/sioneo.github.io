插件报错

下面列出一些常见的插件报错以及解决方法。需要注意的是，几乎所有插件报错（Plugin Error）都可以通过禁用插件来解决，但这只能算得上是一个临时解决方案，这里介绍的都是从根本上解决的方案。

  1. 插件重复类错误
    XXX is alrealy in use. Use another id or add "override": true to your plugin.
    或    A manifest id of XXX was defined before in XXX; ensure that you have no duplicates.

    出现这两个错误说明plugins文件夹中存在重复的插件，依照报错插件的文件路径将其删除即可。

  2. 草稿缺少ID
    Item may not be null!

    出现这个错误说明有一个草稿缺少ID

  3. 草稿缺少类型
    May not find a loader for type not defined

    出现这个错误说明有一个草稿缺少类型（type），或类型填写错误

  4. 草稿缺少底座宽度
    When loading XXX: Building width x height must be > 0 but got 0 x X

    出现这个错误说明有一个草稿缺少底座宽度（width）

  5. 草稿缺少底座高度
    When loading XXX: Building width x height must be > 0 but got X x 0

    出现这个错误说明有一个草稿缺少底座高度（height）

  6. 草稿缺少帧
    When loading XXX: No frames have been provided.

    出现这个错误说明有一个草稿缺少帧（frames）

  7. 语法错误类
    info.flowersoft.theotown.util.json.JSONException: ...

    如果你的报错信息以这个开头，那么说明你的JSON代码可能存在语法错误，你可以使用一些JSON语法检查器或者使用AI帮你解决语法问题。
