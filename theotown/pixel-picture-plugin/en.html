Usage Guide

The Pixel Picture Generator (PPG) creates pixel art pictures in TheoTown. It consists of two parts: the base plugin (PPG_base) and the generator (PPG_generator).
Steps:

  1. Install the base plugin first. You can download it below; install it like any other plugin by putting it into the game's plugins folder. The base plugin provides the game content needed to display pixel art (once installed, it also lets you see pixel art generated by others).
  2. Then create and export a generator. As the name suggests, the generator is what builds the pixel art on the map.
Usage Guidelines
  1. Images imported must be materials that you own the copyright to, have obtained authorization for, or are free to use; you must not import images for which others hold the copyright.
  2. It is not recommended to use this for generating images that violate laws and regulations, contain pornography or violence, are politically sensitive, or promote discrimination or insults, or other inappropriate content.
  3. It is recommended to indicate "Generated by PPG." Do not falsely claim that it was made entirely by hand, and do not misrepresent this plugin or the exported generator as your own original handmade work.
  4. The exported generator plugin will embed the images you have selected; please ensure on your own that its use does not infringe upon the rights of third parties.
  5. This tool is provided "as is" without any warranty; losses such as save corruption or data loss caused by use shall be borne by the user, so please back up your saves in advance; adverse consequences such as losses caused by violating the above guidelines shall be borne by the user.

Create a Generator

First import the image you want to turn into pixel art (JPEG/PNG/WEBP/AVIF format), then set a suitable scale so that it will not overflow the map when generated. Once it looks right, click the Export button and the plugin will be downloaded. You can find the generator's category in the root (outermost) menu of the build interface.
