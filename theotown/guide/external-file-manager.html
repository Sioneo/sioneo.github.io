使用外部文件管理器管理文件

大多数时候使用外部文件管理器管理游戏文件会方便一些，我们现在来了解一下。


安卓

在安卓平台上，我们通常使用MT文件管理器管理文件，点击此处下载。下载之后我们依照这个路径：/storage/emulated/0/Android/data/info.flowersoft.theotown.theotown/files/找到游戏的文件夹。


iOS

iOS上就相对简单，只须打开系统自带的“文件”应用然后打开“TheoTown”的游戏文件夹即可。


Windows

在Windows上你可以在C:\Users\{你的用户名}\TheoTown\下找到游戏的文件夹。


Linux (Arch Linux)

在Linux上你可以在/home/{你的用户名}/TheoTown/下找到游戏的文件夹。


找到游戏的文件夹之后，你就可以进行一些文件操作，例如导入插件、备份存档等。这些操作跟使用内置文件管理器是一样的，例如导入一个外部插件只须将插件文件复制到/移动到plugins文件夹中即可，而备份游戏存档你就可以便利地直接复制游戏文件夹进行备份。
